# Project Hub

My portfolio website.

- `index.html` — home page: the project squares
- `about.html` — About me
- `project.html` — the page each project opens (video, how it works, why I built it)
- `projects.js` — the list of projects (empty for now)
- `site.css`, `site.js` — shared style, menu and search
- `assets/images/` — cover pictures and my photo
- `assets/videos/` — demo videos

Open `index.html` in a browser to see it.
